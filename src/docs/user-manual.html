User Manual

RepairCafe — repair tracking for a sustainable future — v1.24

Overview

RepairCafe is a web application for tracking repair items at Repair Cafe sessions. Volunteers use it to register items brought in for repair, assign repairers, record outcomes, and review how each session went.

The app is hosted online and works on any modern browser — no installation needed.

Logging In

Click one of the login buttons in the top-right corner of the header:

ButtonMethod
Envelope iconEmail address and password
Google iconSign in with a Google account
Apple iconSign in with an Apple account

Once logged in your name appears in the header. Admin-only features (Admin panel, Issues log) become visible. To log out, click the arrow/logout icon in the top-right corner.

Creating a Repair Record

Click New in the header to open the new repair form and fill in the following fields:

FieldDescription
OwnerName of the person who brought the item
Item TypeCategory of the item (e.g. Clothing, Electronics)
DescriptionBrief description of the item and the fault
RC DayThe session date this item belongs to
Primary RepairerThe volunteer assigned as the lead repairer
Secondary RepairersAdditional volunteers assisting (optional)
StatusCurrent repair status (defaults to New)

Click Save to create the record, or Cancel to discard it.

Repair Statuses

StatusMeaning
NewItem registered, not yet assigned to a repairer
AssignedA repairer has been assigned and is working on it
RepairedItem successfully fixed
Advice GivenItem could not be repaired; advice was provided to the owner
Partially RepairedSome repair was carried out but the item is not fully fixed
Not RepairedItem could not be fixed and no further action taken

Session Schedule

Click the Sessions button to view the Repair Cafe calendar. Sessions are held on the 3rd Saturday of every month.

Next Session banner

The highlighted card at the top shows the next upcoming session with a countdown in days and the number of pre-registered items.

Month cards

Each month is shown as a card displaying the date. Cards with repair items also show:

  • A 🛠 item count badge
  • A mini donut chart showing the status breakdown at a glance, using the same colours as the session dashboard

Use the year buttons to switch between years. Click any card to open the Session Dashboard for that date.

Repairer Dashboard

Each repairer has a personal dashboard showing all items assigned to them, either as primary repairer or as a helper.

How to open

  1. Go to Admin → Repairers
  2. Click the chart icon next to the repairer's name

What it shows

  • Total Assigned, As Primary, As Helper, Completed stat cards
  • A donut chart of repair statuses across all assigned items
  • A table of every assigned item with session date and role (Primary / Helper)

Issue Tracker

Use the issue tracker to log operational problems or improvement ideas (e.g. equipment faults, process suggestions). Access it via the Issues icon in the header — logged-in users only.

A count badge on the Issues button shows the number of open issues at a glance.

Reporting an issue

  1. Click Report Issue
  2. Enter a description of the issue
  3. Click Submit Issue

Managing issues

ActionHow
Edit descriptionClick the description text to edit inline. Press Enter or click away to save; Escape to cancel.
Enter a fixClick the Fix cell and type the resolution. Press Enter or click away to save.
Change statusUse the dropdown: New Assigned Fixed
Sort by statusClick the Status column header — toggles ascending/descending order
DeleteClick the 🗑 icon on the row
Amber highlight: Issues with no fix entered are shown with an amber left border so they stand out and can be actioned quickly.

Admin Panel

Accessible to logged-in users via the Admin (grid) icon in the header.

Repairers

Make Primary / SecondaryToggle whether the repairer appears in the primary repairer list on new repair forms

Database Explorer

A full searchable view of all repair records across every session. Click a row to open the full repair detail. Use the print icon on a row to generate a PDF repair receipt in a new window.

User Manager

Lists every user who has ever logged in. Admins can grant or revoke admin access here.

Version Manager

Displays the current application version and description. The version shown in the header and footer always reflects the latest deployed code automatically — no manual update needed after a deployment.

Tips

  • The version shown in the header updates automatically on every new deployment — you never need to set it manually.
  • Secondary repairers can be added or removed directly from the session dashboard without opening the full edit form.
  • Past session cards on the schedule screen show a mini donut chart so you can see at a glance how a session went.
  • The Issues badge count keeps open issues visible at all times without having to visit the tracker.
  • Status changes made in the session dashboard items list are saved to Firestore immediately — no separate save step required.
